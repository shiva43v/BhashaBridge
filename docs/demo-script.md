# Demo script
1. Create a call: Ravi speaks Hindi / hears Telugu; Suresh speaks Telugu / hears Hindi.
2. Open Ravi's page and Suresh's invite link in two windows; both click Join call.
3. Ravi says a Hindi sentence about a doctor appointment; Suresh hears Telugu and both transcripts update.
4. Suresh replies in Telugu; Ravi hears Hindi.
5. End the call; show the summary tabs, action items and speed figures.
